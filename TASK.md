# Calendar Coding Exercise

## The project
Build a small, usable calendar system with the help of an AI coding assistant.

You should use the AI assistant to help write the implementation. You may also write, edit, or replace code yourself whenever you wish. We are interested in the finished system and how you work with the assistant to produce it.

We expect this exercise to involve less than 60 minutes of work, although you may spend more time if you choose.

Use any programming language and tools you are comfortable with.

## Core capabilities
Your calendar should allow someone to:
- Add, reschedule, and cancel events.
- Support recurring calendar events with exceptions.
- View the resulting calendar and its scheduled events (can be very simple).

Provide a practical way to run and observe the system. This could be a command-line interface, demonstration script, API, minimal user interface, or another approach you consider appropriate.

The interface, data model, output, and detailed calendar behavior are up to you. Make reasonable choices and describe important assumptions in your README.

## Extensions
Implement at least one of the following:
- Detect and explain conflicting events.
- Recommend available time slots for a meeting of a given length; include suitable working hours or another search window so recommendations occur at useful times.
- Recommend meeting times across multiple attendees or calendars.
- Improve performance for a calendar containing a large number of events.
- Add a full graphical user interface.
- Any other features of similar complexity that show off your talents.

## Library restriction
Do not use a calendar or scheduling library that implements the main calendar behavior or either of your chosen extensions for you.

Standard language libraries, testing tools, web frameworks, and date/time utilities for parsing, comparison, time zones, and formatting are allowed. The calendar and scheduling logic should be part of your own solution.

## Submission
- Source code and automated tests
- Instructions for running the system
- A short README covering assumptions, completed work, approximate time spent, and what you would do next
- The task-specific transcript from the AI coding assistant (Claude Code: run `/export AI_TRANSCRIPT.txt` in the task session)

Include only the conversation for this exercise. Remove secrets, credentials, personal information, and unrelated content before submitting.
